## 前一轮定位协议

- 黑碗成功／失败两条用于开发、定位物体混淆和边界问题。抽屉任务在设计固定后验证，不能根据结果继续调整本轮提示词；该任务曾出现在历史轮次，不能称为全新未见测试集。
- 首轮验证因代码审计发现恢复判断可绕过边界否决、提示词会混淆短暂抓取与后续正常释放而中止；修正后固定实现重跑三条，未根据中止任务的视觉输出调整设计。
- 固定官方 Qwen3-VL-4B-Instruct revision、BF16、greedy、seed 7。最终默认双视角、1 Hz、每次 4 个相邻时刻加首帧参照。较旧方案还改变了视角和采样密度，因此不是单变量消融。
- 不把参考帧号、success 或事后人工物体描述喂给最终模型。开发阶段单独试过原生 video 输入与人工物体描述诊断；未发现稳定改善，没有并入最终实现。
- 工程测试检验输入只读、边界合法性、缺失前置不会抹除后续目标、回退／恢复约束和前端视频保留。**测试通过不等于视觉识别正确。**

## 如何评价与解释

先按任务语义对齐预期事件，再检查模型拆解是否漏掉目标；不能只用模型自己生成的目标数作为分母。例如漏掉“关抽屉”，即使其他目标全部定位，也不是完整成功。

对已匹配事件同时检查：区间与参考是否相交、区间宽度、到参考区间的最近时间距离、错误物体／错误状态、未定位数量。参考本身有不确定性，相交只是必要检查之一，不是正确性的充分证明；用半条轨迹覆盖答案不应算准确定位。初始满足单独统计，不算新产生的正面事件。

本实验只有两类任务、三条轨迹，不能据此报告具有泛化意义的准确率。后续需要不同初始状态、真实掉落／恢复、已持物起点，以及双人核验的独立检查集。
